MoOS UTM Net Installer — quick start
====================================

Requirements: UTM with JIT is strongly recommended. UTM SE can import this VM,
but its interpreter is much slower. Keep at least 18 GiB of free phone storage.

1. Copy MoOS-UTM-Installer.utm.zip to your iPhone (Files app).
2. Unzip it, then share MoOS-UTM-Installer.utm to UTM.
3. Start the imported VM (1.5 GiB RAM / 2 CPU iPhone 13+ profile).
4. Keep UTM on its Emulated network and choose "Install latest signed MoOS".
5. Wait for download, signature verify, and install.
6. Reboot when prompted.
7. MoOS starts from the persistent target disk.

Updates happen inside MoOS later — you do NOT re-import this bundle.

Serial diagnostics: UTM → Terminal (ttyAMA0).

OWNER iPHONE TEST REQUIRED before calling this final.
