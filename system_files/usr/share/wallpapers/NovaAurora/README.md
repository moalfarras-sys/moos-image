# Nova Aurora — شفق نوفا

حزمة خلفية MoOS أصلية: master ‏4K حقيقي مع نسخ 21:9 و16:10، ووضعين فاتح وداكن. الحقل اللوني مولّد مباشرة على canvas ‏3840×2160، والشعار مركب من master شفاف بدقة أعلى من حجم العرض.

Original MoOS wallpaper package with native 4K, 21:9 and 16:10 outputs in light and dark modes. PNG files are sRGB and generated reproducibly by `artwork/generate_nova_visuals.py`.
