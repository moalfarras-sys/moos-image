# Nova Deep — عمق نوفا

حزمة خلفية MoOS أصلية هادئة تعتمد المدارات والعمق البصري، مع master ‏4K حقيقي ونسخ 21:9 و16:10 بالوضعين.

Original calm orbital MoOS wallpaper package with native 4K, 21:9 and 16:10 outputs in light and dark modes. PNG files are sRGB and generated reproducibly by `artwork/generate_nova_visuals.py`.
