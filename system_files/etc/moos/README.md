# /etc/moos — إعدادات MoOS على مستوى النظام

هذا المجلد يُنسخ كما هو إلى `/etc/moos/` داخل صورة MoOS، وهو المكان الموحد لأي إعدادات نظام خاصة بـ MoOS (هوية الإصدار، إعدادات Mo AI الافتراضية، إعدادات MoOS Updater... إلخ). في M0 هو هيكل فارغ فقط.

آخر تحديث: 2026-07-09

## ملاحظات (Notes)

- على أنظمة bootc/ostree، محتوى `/etc` القادم من الصورة يُعامل كـ defaults: تعديلات المستخدم المحلية تُدمج عبر 3-way merge عند كل تحديث. أي إعداد لا يحتاج تعديل المستخدم يُفضَّل وضعه تحت `/usr/lib/` بدلاً من هنا.
- ملفات الإعداد الفعلية (مثل `moai.conf`, `updater.conf`) تُضاف في Phase 7 — انظر `MOOS_BUILD_WORKFLOW.md` في جذر المشروع.

## قيود معروفة (Known Issues)

- المجلد placeholder في M0 — لا يحتوي إعدادات فعلية بعد.
