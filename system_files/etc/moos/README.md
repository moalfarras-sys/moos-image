# /etc/moos — إعدادات MoOS على مستوى النظام

هذا المجلد يُنسخ كما هو إلى `/etc/moos/` داخل صورة MoOS، وهو المكان المحجوز لإعدادات MoOS النظامية التي لا تنتمي إلى معيار أو تطبيق آخر.

آخر تحديث: 2026-07-09

## ملاحظات (Notes)

- على أنظمة bootc/ostree، محتوى `/etc` القادم من الصورة يُعامل كـ defaults: تعديلات المستخدم المحلية تُدمج عبر 3-way merge عند كل تحديث. أي إعداد لا يحتاج تعديل المستخدم يُفضَّل وضعه تحت `/usr/lib/` بدلاً من هنا.
- لا يُضاف ملف إعداد بلا مستهلك فعلي واختبار لعقده. إعداد Mo AI الحالي موجود في وحدة المستخدم وملف المستخدم الاختياري `~/.config/moos/moai.env`.

أي إعداد جديد هنا يجب أن يملك قارئًا فعليًا وتوثيقًا واختبارًا.
