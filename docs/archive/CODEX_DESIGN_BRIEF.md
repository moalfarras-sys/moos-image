# CODEX_DESIGN_BRIEF — ارفع MoOS لنظام فاخر كامل (من داخل الجهاز)

> **لمن:** Codex، يعمل **داخل MoOS المثبَّت على العتاد الحقيقي** (i5-14400F / RTX 2080 SUPER عبر **nouveau + NVK** / Plasma 6 Wayland / Btrfs / bootc-OSTree) وعلى مستودع `moos-image/`.
> **المهمة:** ارفع MoOS إلى **نظام مبهر كامل بمستوى iOS‑27**، صقل التطبيقات، وواصل التطوير — **بأعلى جودة وبلا كسر الإقلاع إطلاقاً**.

---

## 0) ميزتك الحاسمة — استغلّها
أنت **ترى سطح المكتب وتختبر حياً على GPU حقيقي**. Claude على ويندوز بلا شاشة — لا يستطيع رؤية النتيجة، فيعمل «أعمى». **أنت العين.** دورة عملك:
> عدّل `moos-image/` → `git pull` (Claude على نفس الريبو — اسحب أولاً) → commit → push → CI يبني → على الجهاز `sudo bootc upgrade && systemctl reboot` → **سجّل دخول وانظر** → صوّر → اصقل. لا ترقيع حي كحل أساسي — عدّل المصدر.

---

## 1) القاعدة التي لا تُكسَر أبداً: **لا تكسر الإقلاع**
النظام أُنقِذ للتوّ من قفلة GRUB «can't allocate kernel / out of memory». الإصلاح في `build.sh` **مقدّس — لا تلمسه:**
- توليد الـ initramfs (المرّتان)، `omit_drivers` (nouveau/amdgpu/i915/nvidia)، `--no-hostonly`، فرض وحدة ostree، حراس `ostree-prepare-root`.
- **حارس حجم الـ initramfs** (يفشل البناء فوق 300MB) — لا ترفعه، لا تضف تعريفات/firmware ضخمة للـ initramfs.
- **الإصدار:** المستخدم يشغّل النسخة **العامة `moos` (nouveau/NVK — تقلع + Vulkan يعمل)**. **لا تبدّله لـ `moos-nvidia`** (الاحتكاري يُطفئ الشاشة — يحتاج nvidia في الـ initramfs = كبير جداً).
- kargs، GRUB، BLS، bootc install، ختم plymouth.
**بعد كل تغيير:** تأكّد أن CI ينجح (حارس الحجم) **وأن النظام ما زال يقلع** (أعد التشغيل، صِل لـ SDDM+Plasma). لو تغيير يهدّد الإقلاع — لا تشحنه.

---

## 2) مطبّات تقنية (لا تتعلّمها بالطريقة الصعبة)
- **كاش QML:** `qml-qt6` يحمّل كاشاً قديماً عبر ترقيات ostree. المُشغّلات الآن `rm -rf ~/.cache/qmlcache` + `QML_DISABLE_DISK_CACHE=1`. **أبقِها.** اختبر QML بالفتح من **البار** لا الطرفية فقط.
- **تطبيق الثيم:** Plasma 6 يطبّق جزءاً فقط من الثيم الافتراضي. `moos-apply-theme` (autostart، علامة مُصدَّرة `THEME_REV`) يطبّق الكل مرة لكل مستخدم. **ارفع `THEME_REV`** عند أي تغيير لأصول Nova ليُعاد التطبيق للمستخدمين الحاليين.
- **اختبار QML الدخاني** في build.sh: تطبيقات Kirigami لا تُنشئ نافذة headless — الاختبار يتسامح (يفشل فقط على خطأ `file.qml:line:col` حقيقي). أبقِ QML متوازن الأقواس، تحقّق بـ `qmllint`.
- QML النقي بلا Process/كتابة ملفات — التطبيقات تتصرّف عبر معالج `moos://` (`moos-open`) + سكربتات + خدمة تحكّم محلية (`moai-control` :8079).

## 3) المهمة — 3 مسارات

### المسار A — هوية بصرية فاخرة (مستوى iOS‑27، **أصلية**)
موجود وقوي: خلفية Nova، ألوان NovaDark، مؤشر NovaIce، أيقونات Nova، splash، أصوات، SDDM، plymouth. **النواقص (أسباب «ما زال شكل KDE»):**
1. **زخرفة النوافذ** = `org.kde.breeze` معاد تلوينه. **ابنِ زخرفة «MoOS Nova» أصلية** (Aurorae SVG، أو اضبط Klassy إن أضفته): زوايا مدوّرة، شريط عنوان مصقول، أزرار أنيقة، ظل ناعم. فعّلها في `/etc/xdg/kwinrc [org.kde.kdecoration2]`.
2. **ستايل الودجت (QStyle)** غير مضبوط → Breeze. اشحن واضبط ستايل Nova (ثيم **Kvantum** «MoOS Nova» = زجاج شفاف + زوايا مدوّرة) في `/etc/xdg/kdeglobals [KDE] widgetStyle`.
3. **desktoptheme Nova** ~90% Breeze عبر FallbackTheme. أنشئ FrameSvg الناقصة (خلفية اللوحة = عائمة شفافة، خلفيات الودجت، tooltips، أزرار المهام) لتصير اللوحة بشكل Nova لا Breeze.
4. **البار/الرصيف:** اجعله **عائماً، شفافاً (blur)، مدوّر الحواف**، بمسافات نظيفة ومؤشّر نشط واضح (المستخدم قال «شكله عادي»). عدّل قالب التخطيط + إعداد اللوحة.
5. **SDDM + القفل:** تأكّد أن خلفية Nova Horizon II **تظهر فعلاً** (المستخدم رأى خلفية عامة — تحقّق حياً أن `Current=moos-nova` نشط والثيم يُحمّل والمسار يُحلّ).
6. **الحركة:** حركات سريعة أنيقة بإحساس iOS (فتح/إغلاق scale+fade، blur خلف الطبقات).

**مصادر التصميم (إلهام فقط — أنتج أصولاً أصلية لـ MoOS، بلا نسخ علامات تجارية 1:1):** ادرس **Layan · Colloid · WhiteSur · Orchis · Graphite** (ثيمات GTK/KDE)، بنية ثيمات **Kvantum**، صيغ زخرفة **Klassy/Aurorae**، ووثائق Plasma theming. التزم نظام تصميم Nova متماسكاً (زجاج كحلي، تدرّج cyan→blue→violet، خط IBM Plex، زوايا كريمة، ظلال ناعمة).

### المسار B — Mo AI مساعد قوي حقاً
موجود: بث حي، محلي+سحابي (مفتاح في Secret Service)، إعدادات داخلية ⚙، تنفيذ بضغطة، فحص نظام، مُشغّل برمجة، عقل v2 أذكى. **قوّه أكثر:**
1. **عرض الأكواد:** كتل كود بتلوين صياغة + زر نسخ لكل كتلة.
2. **الوكلاء من الداخل:** إجراء «برمجة» يطلق Claude Code/Codex؛ أضف **وكيلاً سحابياً ثانياً** + منتقي للوكيل ومجلد المشروع بواجهة أنيقة. فكّر بوضع «مطوّر» داخلي.
3. **إصلاح حقيقي:** وسّع `moai-do` بأفعال آمنة مؤكّدة (fix-display، fix-network، free-space، restart-service) — كلها whitelist + pkexec + تُعرض قبل التنفيذ.
4. **بطاقات وصقل:** بطاقات رسائل/إجراءات، ترويسة أنظف، حفظ/استرجاع محادثات، حالة النموذج/GPU/الذاكرة.
5. **آمن دائماً:** تأكيد قبل تحديث/تثبيت/حذف/إعادة تشغيل/rollback؛ لا shell جذر، لا أوامر خفية.

### المسار C — التطبيقات واكتمال النظام
دقّق واصقل كل تطبيق (Welcome, Compatibility Hub, Hardware, Updater, Recovery, Mo Remote) لنفس المستوى: بطاقات وأيقونات متسقة، بلا مُشغّل مكرر، بلا تعطّل بدء، ملفات desktop صحيحة. المُحدِّث يعرض الإصدار/digest/staged/rollback؛ الاسترجاع يعرض النشرات. صفر هوية Fedora/Breeze مرئية (حارس CI موجود).

## 4) بوابات القبول (Quality bar)
- بعد أول دخول: سطح مكتب **فاخر بوضوح ومميّز عن KDE الافتراضي** (زخرفة + بار + ستايل — لا الخلفية فقط).
- يقلع بثبات (nouveau)، لا شاشة سوداء، لا emergency، initramfs تحت الحارس.
- Mo AI يفتح الواجهة الجديدة **من البار**، يعرض أكواداً، يطلق وكلاء، ينفّذ إصلاحات آمنة.
- صفر هوية أجنبية مرئية؛ SDDM + plymouth = Nova.
- CI أخضر (بناء + حارس حجم + QML smoke + هوية + اختبار إقلاع).

---

## 5) أمان + تنسيق
- تأكيد قبل أي فعل لا رجعة فيه أو يغيّر النظام. **لا تكسر الإقلاع مقابل الشكل.** اختبر على GPU الحقيقي. كن صادقاً بما اختُبر وما لم يُختبر.
- **نفس الريبو مع Claude:** `git pull` قبل كل push. Claude يملك إصلاحات الإقلاع/CI/initramfs (لا تُرجِعها) وكتب `CODEX_HANDOFF.md` والذاكرة. **أنت تملك الصقل البصري وتجربة التطبيقات (لأنك ترى الشاشة).** التقسيم: Claude = بنية/صحة (أعمى)، Codex = تصميم/UX (مُبصِر).
