# MoOS fixes — 2026-07-15 (session B) · one unified premium system

A full-system audit (4 parallel review agents) + fixes, driven by the owner's rule:
**MoOS is ONE system — modify the base in place, never layer a duplicate on top; make
it premium and bug-free.** Every fix below is in the source repo (parity with the
running machine). The ISO is intentionally NOT built yet — finish all edits first.

See also the enduring principles now in agent memory: one-system, source↔device
parity, dev-mode password, ISO hold.

---

## Shipped (committed + pushed to `main`)

### Development ergonomics
- **Dev-mode passwordless admin** — `system_files/usr/share/polkit-1/rules.d/50-moos-devmode.rules`.
  Local+active+wheel user runs bootc/rpm-ostree/moos-* /moai-do without a password
  during development. **TEMPORARY — delete this file before release.** (49-moos-installer.rules kept.)

### Correctness / blockers
- **Mo Store installs (appimage/web)** — `moos-install` joined the recipe with a TAB and
  read it with `IFS=$'\t'`, coalescing the empty fields of appimage/web kinds and
  shifting every later field left → every non-Flathub install failed. Now `\x1f`.
- **Installer is ONE path** — removed the "Advanced / dual-boot → raw Anaconda" branch:
  it opened a second installer window over the QML one, and its kickstart did
  `clearpart --all` (erase ALL disks) under a "keep your OS beside it" label. QML
  "Erase & install" is now the only route; Anaconda stays only as live-ISO infra.

### One-system consolidation
- **One visible store** — Bazaar was preinstalled AND its launcher never hidden, so a
  fresh device showed Mo Store *and* Bazaar. Now Mo Store is the single visible store;
  Bazaar is its optional on-demand full-catalog engine (`moos-store-browse`,
  `moos://store/browse-all`, a "Browse all" pill in the store header, launcher hidden
  on install). Discover stays engine-only. Removed Bazaar from `iso/flatpaks.list` and
  the default device-plan; relabelled in moos-setup.

### Identity (leftover "Nova" scrub, user-visible)
- Sound theme name `MoOS Nova` → `MoOS` (`sounds/moos/index.theme`).
- Panel clock metadata "Nova time and date" + stale German `Name[de]` scrubbed.

### Premium screens
- **Panel clock popup** — was a bare MonthView; now the MoOS clock identity (large light
  time + bilingual date + accent) above the calendar.
- **Logout (light theme)** — was a stale copy with no entrance animation; now identical
  to dark (palette-driven), so both themes get the premium fade/rise.
- **Device-health widget** — rendered into a ~3px sliver (a nested layout defaulted
  `fillWidth=true` and ate the row). Rebuilt as premium **animated CPU/RAM/Disk rings**
  (`MetricRing.qml`, QtQuick.Shapes arcs, count-up, motion-gated); verdict strip pinned
  to a fixed width. Dead GPU pill (nothing on NVK) → Disk ring. Gates updated to match.

### Local AI (Mo AI)
- `moai.service` capped context (`--ctx-size 4096 --ngl auto`) so llama.cpp can't
  project tens of GB of VRAM and SIGABRT/crash the compositor on the 8 GB shared card.
- `moai-gateway have_network()` now also requires the runtime-container registry
  (quay.io/ghcr.io), not just the model registry — a fresh pull needs both.
- Runtime stays RamaLama + **Qwen3-4B** (best quality-per-GB that fits 8 GB shared VRAM;
  strongly multilingual incl. Arabic for the Arabic-first UI).

### Latent script defects (full-system sweep)
- `moos-install-to-disk`: a JSON null/bool account field no longer coerces to
  "None"/"True" (a null password would have hashed to the word "None").
- `moos-hardware-adapt`: RAM tier rounds to nearest GiB (8 GB was read as 7, wrong zram tier).
- `moos-ui-migrate`: stale-desktop cleanup derives from `$HOME`, not a hard-coded `/var/home/mo`.

## HELD — needs the owner's explicit decision

- **Mo PC Remote LAN default** — the connection can't start because the .NET agent's
  `AllowLan` defaults to **false**, so it 403s the phone's LAN address (the very URL/QR
  the panel shows) while Tailscale ships logged out. The fix (default `AllowLan=true`;
  public internet still blocked by NetworkGuard, PIN still required) is a **security-
  posture change** and was withheld from auto-commit pending the owner's OK.
