# 2026-07-16 session F — the brand session: the vector logo, animated, everywhere

The owner delivered the MoOS mark as vectors (`artwork/logo/`, traced by
VTracer from the original 3D render) and asked for a modern, animated brand
across the system: login, logout, the bar, per-theme wallpapers, a new widget,
and polish. Everything below is on `main`, gates green, each new gate broken
on purpose once and watched go red.

## What landed

1. **The logo, replaced at the source.** High-detail SVG → supersampled
   renders for the canonical pixmap, `/usr/share/moos`, hicolor 48–256, all
   six LNF splash marks; the Plymouth watermark regenerated from the canonical
   (generate_boot_hero.py reads it). The new renders are TRANSPARENT — the old
   PNG carried a baked glow square. The Lottie file in the delivery contains
   ZERO keyframes (a static vector in a Lottie envelope), so all motion is
   plain QML — which plasmashell surfaces required anyway (Lottie is banned).

2. **Login scene** — `org.moos.ui2.greeter`, a Plasma/Wallpaper package the
   greeter's wallpaper process loads (plasmalogin's own QML is compiled into
   the binary; the wallpaper is the surface the image owns — verified against
   plasma-login-manager v6.7.2 source). Graphite backdrop, drifting aurora
   bands, breathing cyan/violet halo, two counter-orbiting sparks, staged
   wordmark entrance. Emblem is screen-relative (gridUnits left it 117px on a
   4K panel). The drop-in still names /wallpapers/MoOSUI2Graphite so the
   login==lock relationship gate keeps reading the truth.

3. **Lock screen** — the shell-override brand is now the same living mark, and
   the clock got a FLOOR below the brand: the halfway formula parked 22:57
   inside the emblem on 4K (found via kscreenlocker_greet --testing).
   Also learned: a *partial* user-local shadow of the shell package makes
   kscreenlocker fall back to its built-in locker ("Lockscreen QML outdated" —
   verifyPackageApi needs metadata.json's X-Plasma-APIVersion beside the QML).

4. **Logout** — animated brand atop the glass panel, a draining countdown
   hairline, and a SHIPPED BUG fixed: every action icon drew as a solid teal
   blob. The buttons recolour via isMask and MoOSUI2's 32px action icons are
   full-colour discs — masked featureless. All nine buttons now use -symbolic
   glyphs (cancel-operation-symbolic for Cancel: KIconLoader falls back to the
   same-theme non-symbolic blob before trying inherited themes).

5. **The bar** — `org.moos.brand`, the ONE MoOS mark in the panel, and it
   moves: idle breath, hover halo, press flourish; its popup is the MoOS
   glance (version, uptime, Store/Mo AI/Updates/Theme/Settings/Recovery).
   Kickoff stays the launcher and wears view-app-grid-symbolic. New users:
   layout.js; existing desktops: THEME_REV 17→18 migration, add-only.
   Qt 6 gotcha: QML XHR cannot read file:// (no QML_XHR_ALLOW_FILE_READ in
   plasmashell) — os-release/uptime read via the P5Support executable engine.

6. **Wallpapers** — every family theme now has designed art, not a blurred
   gradient: glass waves in the Graphite master's language, per palette,
   deterministic (make_wallpaper rewrite). Canva was requested but the
   account's AI quota answered every call with a hard error; the generator
   ships the art and Canva can replace the masters later without touching
   packaging.

## Gates added (all bitten once)

- login WallpaperPluginId is a relationship: org.moos.* ids must exist in-tree
  (main.qml + Image config key + matching config group) and resolve on-image.
- every QML naming images/*.png sprites must ship the sprite beside it.
- the lock clock keeps its Math.max floor below the brand.
- logout iconName values must end -symbolic.
- layout.js must add org.moos.brand AND re-point kickoff's icon (half = the
  double-logo bar or the logo-less bar).
- org.moos.brand: complete package, no ShaderEffect/MultiEffect/Lottie/
  pkexec/sudo (checked with code() — the header names those bans in prose).

## Test-harness notes for the next session

- Logout: `/usr/libexec/ksmserver-logout-greeter --windowed --lookandfeel
  <id>` with a user-local LNF copy under a TEST id.
- Lock: full lockscreen dir + the shell metadata.json into
  `~/.local/share/plasma/shells/org.kde.plasma.desktop/`, then
  `kscreenlocker_greet --testing`. Partial shadows fall back to the failsafe.
- Applets: `plasmawindowed org.moos.brand` (flip preferredRepresentation to
  fullRepresentation in the shadow copy to see the popup).
- ALWAYS delete the shadows afterwards (shadowed-config trap).
- `pkill -f <name>` kills the test shell itself when the pattern appears in
  its own command line — use `kill $(pgrep -f 'patter[n]')`.
